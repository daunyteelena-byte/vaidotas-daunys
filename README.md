# Vaidotas Daunys (1958–1995)

Svetainė apie poetą, eseistą ir redaktorių Vaidotą Daunį bei Vaidoto Daunio fondą.

Statinė svetainė: `index.html` + `assets/style.css`. Peržiūrai pakanka atidaryti `index.html` naršyklėje.

## Pradinė informacija

Pirmoji versija parengta pagal viešus šaltinius (VLE, Vikipedija, „Krantų“ redakcija, Rokiškio J. Keliuočio biblioteka, tekstai.lt). Tekstai perrašyti savais žodžiais.
